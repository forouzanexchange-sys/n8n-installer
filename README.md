# n8n Installer

نصب خودکار و امن **n8n** به همراه **Caddy** جهت مدیریت خودکار گواهی SSL (HTTPS) و پروکسی معکوس بهینه‌شده برای جریان داده‌های زنده (SSE).

این اسکریپت آخرین نسخه پایدار n8n را به همراه وب‌سرور سبک Caddy درون کانتینرهای Docker راه‌اندازی می‌کند و از پایداری داده‌ها، پشتیبانی از هوش مصنوعی و جریان زنده داده‌ها (Real-time Streaming) پشتیبانی می‌نماید.

---

## پیش‌نیازها

- سرور تازه با سیستم‌عامل **Ubuntu 22.04** یا **24.04**
- دسترسی **root** یا **sudo**
- دامنه یا زیردامنه با رکورد `A` متصل به IPv4 سرور (مثلاً `n8n.example.com`)
- پورت‌های TCP **80** و **443** آزاد و باز باشند
- در صورت وجود رکورد `AAAA`، اتصال IPv6 سرور باید فعال و سالم باشد.
